# RICE-Prioritization-Tool
Описание: CLI + веб-инструмент для приоритизации фич по методологии RICE.

# RICE Prioritizer

RICE = (Reach × Impact × Confidence) / Effort

## CLI
```bash
python cli.py list
python cli.py add --name "New Feature" --reach 1000 --impact 2 --confidence 0.8 --effort 3
```

## Web
```bash
streamlit run app.py
```
